# Partner Pilot — Icestasy Projects Pvt Ltd

A static, beginner-friendly partner opportunity tracker built with HTML, CSS, and JavaScript. It needs no installation, build step, API key, or paid service.

## Open the app on your computer

1. Extract the download ZIP into a folder.
2. Open the extracted folder.
3. Double-click `index.html`.

The demo saves prospect records in the browser on that device. It does not sync data between people or devices. The sample records are fictional; do not enter real customer information in this showcase demo.

## Publish the app with GitHub Pages

1. Sign in to GitHub and create a **Public** repository named `Partner-Pilot`.
2. Extract the ZIP on your computer and open the extracted folder.
3. In the new repository, choose **Add file → Upload files**. Drag the contents of the extracted folder into the upload area, including `index.html`, `Logo.png`, `README.md`, `.nojekyll`, and `.gitignore`.
4. Enter a commit message such as `Add Partner Pilot app`, then choose **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait a few minutes. GitHub Pages will show the public website address on the Pages settings screen.

Keep `index.html` and `Logo.png` together in the repository root so the app can find its logo. No build command or framework setting is needed.

## Publish on Vercel later

1. Sign in to Vercel and choose **Add New → Project**.
2. Import the `Partner-Pilot` GitHub repository.
3. Leave the framework as **Other** and the build and output settings blank.
4. Choose **Deploy**. Vercel will provide a public link and can redeploy after future GitHub updates.

## Included features

- Dashboard counts, prospect management, pipeline stages, and follow-up filters.
- Fictional sample prospects with editable POC and owner details.
- Market choices for Mumbai, Pune, Bengaluru, Hyderabad, and Delhi.
- Copyable outreach prompt labeled as a demo. It does not contact an AI service or send email.
- Icestasy Projects logo.

## Data and privacy

Prospects are saved only in the current browser's local storage. The app does not send them to GitHub or Vercel, and there is no shared database or cloud sync. Clearing browser site data erases saved records. GitHub and Vercel host the app files; they do not host the prospect data entered into the app.
